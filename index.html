응답자료 전 후보 문항 생성

문항 생성은 간단하게, 판단은 전문가가.

측정할 내용과 API 연결만 넣으면 문항 후보군을 생성합니다. 세부 문항 구조는 자동 구성되고, 저장은 연구자 및 전문가가 채택한 문항만 사용합니다.

1. 내용 입력
2. 생성
3. 채택

생성 요청

연구자가 다루고 싶은 측정 내용만 입력합니다.

모델 설정

API 주소는 내부에서 고정합니다. Gemini, OpenAI, Claude 키만 사용할 수 있습니다.

세부 생성 규칙은 내부에서 적용됩니다. 연구자는 결과를 보고 저장할 문항만 채택합니다.
