코드 보기 저장소 응답자료 전 후보 문항 생성

측정할 내용을 입력하면 후보 문항을 만들고, 연구자가 채택합니다.

세부 문항 구조는 화면 뒤에서 자동 구성됩니다. 여기서 생성된 문항은 최종 문항이 아니라 응답자료 전 검토 대상입니다.

1. 내용 입력
2. 생성
3. 채택

생성 요청

연구자가 다루고 싶은 측정 내용만 입력합니다.

정적 GitHub Pages에서 직접 호출합니다. 사용자는 자기 API 키를 입력해야 합니다.

브라우저 직접 호출을 허용하는 API만 사용할 수 있습니다. 서버 프록시는 사용하지 않습니다.

세부 생성 규칙은 내부에서 적용됩니다. 연구자는 결과를 보고 저장할 문항만 채택합니다.
